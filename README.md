# 🛒 Store Products API

API REST para la gestión del catálogo de productos de una tienda, construida con **Node.js**, **Express**, **TypeScript**, y probada con **Jest** y **Supertest**. Desarrollada bajo principios de **Clean Architecture** (Hexagonal) y **GitHub Flow**.
